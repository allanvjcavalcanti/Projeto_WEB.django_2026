# Projeto WEB — Loja de Livros

**Online Bookstore | E-commerce desenvolvido com Django**

## 🇧🇷 Sobre o projeto

Este projeto consiste no desenvolvimento de uma loja virtual de livros, criada utilizando Python e Django.

A aplicação permite explorar um catálogo de livros, pesquisar títulos, navegar por categorias e autores, visualizar promoções e gerenciar pedidos.

## ✨ Funcionalidades

- Catálogo de livros com imagens, preços e descrições.
- Pesquisa de livros.
- Navegação por categorias e autores.
- Seções de livros mais vendidos e promoções.
- Carrinho de compras.
- Finalização e gerenciamento de pedidos.
- Cadastro e autenticação de usuários.
- Perfil de usuário.
- Painel administrativo para gerenciamento da loja.

## 🛠️ Tecnologias utilizadas

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Firebase (dependência presente no projeto)

## 🇺🇸 About the project

This project is an online bookstore developed using Python and Django.

The application allows users to browse a book catalog, search for titles, explore categories and authors, view promotions, and manage orders.

## ✨ Features

- Book catalog with images, prices, and descriptions.
- Book search.
- Category and author browsing.
- Best-selling books and promotions.
- Shopping cart.
- Order checkout and management.
- User registration and authentication.
- User profile.
- Administrative dashboard.

## 🎯 Objetivo | Purpose

Projeto desenvolvido como prática de desenvolvimento web, integração entre tecnologias e construção de aplicações utilizando Django.
